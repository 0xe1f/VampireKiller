# Secrets

## Tipped hourglass

Whip a world [hourglass]({{ '/manual/items/#hourglass' | relative_url }}) once before you grab it. It falls on its side. That pickup is a duration charm, not a second freeze. Rosary, gem, ring, and freeze all run longer until you die. Whip it twice and it is gone.

Vendors hand you the upright hourglass immediately. Nothing to whip there.

## Slime

Some candle drops are [slime]({{ '/manual/items/#slime' | relative_url }}). Catching it is a shrug. Walking away lets a [blob]({{ '/manual/bestiary/#blob-blue' | relative_url }}) hatch.

## Game Master cartridge

Konami sold a cheat cart (RC-735). Plug it in next to the game and three extra manners appear — they live in Vampire Killer, not in the cart. The cart is only a key:

- **STOP** pauses; **;** while paused steps one frame.
- Starting from the title opens a stage / lives menu instead of the intro.
- Game over offers **F5** to continue.

Without the cart, none of that exists. Game Master's own menu does not recognise this ROM.

## What death takes

Leather whip again. Boots, wings, holy water, shields, keys, the tipped-hourglass charm — gone. The [map]({{ '/manual/items/#map' | relative_url }}) stays if you had found one.

## Second loop

Clear Dracula and the castle does not quite end. Difficulty steps up (capped). Same rooms, meaner timing.
